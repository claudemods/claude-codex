# claude-codex
Claude Codex Compendium v1.0 – clone your running Linux system into a bootable live ISO or an Incus container, then install it back to disk with ClaudeInstall. Combines claudebackup-linux, its Qt6 app, claudeinstall-linux and CCCU, with one engine and one build script. Supports Arch, Debian/Ubuntu, Fedora, openSUSE, Gentoo and Alpine.
